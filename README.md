# IELTS 十天冲刺 App

这是把原有雅思十天冲刺网页整理成的移动优先 PWA。

## 已实现
- 8/12、8/13 轻松模式：保留核心任务，其余任务顺延到 8/15、8/16。
- 今日任务、完成打卡、完成率。
- 十天总统计：听力、阅读、真题/剑雅、口语、写作、词汇、错题复盘。
- localStorage 持久化，刷新/重新打开不会丢打卡。
- 每项任务可设置开始时/提前 5/10/15/30 分钟提醒或自定义时间。
- PWA manifest + Service Worker + 离线缓存 + 主屏幕图标。
- 手机端大按钮、单手操作和底部安全区适配。

## 部署
建议用 GitHub Pages / Vercel / Netlify 部署到 HTTPS。PWA 安装和浏览器通知需要安全上下文（HTTPS；localhost 开发例外）。

## iPhone
Safari 打开部署地址 → 分享 → 添加到主屏幕。首次使用点击“提醒”并允许通知。

## Android
Chrome 打开部署地址 → 安装应用/添加到主屏幕。

## 通知限制
当前版本的网页通知检查依赖页面/PWA 的 JavaScript 定时器，因此不能承诺 iOS 在应用完全被系统挂起时仍然按时触发。要实现真正可靠的锁屏后台推送，下一阶段应接 Web Push + VAPID 服务端（或原生推送）。本项目已将通知逻辑独立为 `js/notifications.js`，方便接入。
